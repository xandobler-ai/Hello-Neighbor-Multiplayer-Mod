# Contributing to Hello Neighbor Multiplayer Mod

Thank you for your interest in contributing! Here are some guidelines to help you get started.

## Getting Started

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature-name`
3. Make your changes
4. Test thoroughly in Unreal Engine
5. Commit your changes: `git commit -am 'Add your feature'`
6. Push to the branch: `git push origin feature/your-feature-name`
7. Submit a pull request

## Code Style Guidelines

- Follow Unreal Engine's C++ coding standards
- Use meaningful variable and function names
- Add comments to complex logic
- Keep functions focused and modular
- Use proper error handling

## Testing

- Test in both Co-op and Versus modes
- Test with multiple players when possible
- Check for network synchronization issues
- Verify no crashes or warnings in the Output Log

## Reporting Issues

- Use the GitHub Issues tracker
- Provide clear reproduction steps
- Include error logs and screenshots when relevant
- Specify your Unreal Engine version

## Pull Request Process

1. Ensure your code follows the style guidelines
2. Update documentation as needed
3. Describe your changes clearly in the PR description
4. Reference any related issues
5. Request review from maintainers

## Questions?

Feel free to open an issue or discussion if you have questions about the project.
