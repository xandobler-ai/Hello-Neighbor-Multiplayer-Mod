# Hello Neighbor Multiplayer Mod

## Quick Start Guide

### Installation
1. Extract the mod folder to your Hello Neighbor `Mods` directory
2. Restart the game
3. The mod should be automatically detected

### Game Modes

#### 🤝 Co-operative Mode
- **Players**: 1-4
- **Objective**: Complete all shared objectives together
- **Features**:
  - Team chat and communication
  - Shared resource pool
  - Progress tracking
  - 10-minute default time limit

#### ⚔️ Versus Mode
- **Players**: 1-4
- **Objective**: Outscore your opponents
- **Features**:
  - Individual scoring system
  - Kill/Death tracking
  - Real-time leaderboard
  - 10-minute matches or score limit

### Controls

**Movement**
- WASD - Move
- Mouse - Look around
- Space - Jump (in supported acts)

**Gameplay**
- Left Click - Interact/Attack
- E - Use item
- Tab - View leaderboard (Versus mode)
- Enter - Chat (Co-op mode)

### Configuration

Edit `HelloNeighborMultiplayer/config.lua` to customize:
- Maximum players
- Time limits
- Objective counts
- Network settings
- Gameplay difficulty

### Features

✅ Full multiplayer synchronization
✅ Two distinct game modes
✅ Real-time chat and communication
✅ Network replication system
✅ Customizable settings
✅ Lua-based modular architecture

### System Requirements

- Hello Neighbor (any version)
- 2GB RAM (minimum)
- Stable internet connection for multiplayer
- UE4SS installed and configured

### Known Issues

- Voice chat may have occasional latency
- Maximum 4 players recommended for optimal performance
- Some cosmetic items may not replicate perfectly
